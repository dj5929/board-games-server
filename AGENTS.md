## Agent Rules & Guidelines

To ensure the agent maintains full context without overflowing token limits, the rules and instructions for this repository are modularized into global rules, on-demand skills, and directory-scoped rules.

### Hung-Process Guard (always applied)

* **Stuck process rule:** If any command, background process, or spawned server shows no progress for **more than 5 minutes** (no new output, no finished state), **stop the process** (kill by port/PID directly), then **check its logs** (stdout/stderr files under `C:\Users\omshr\AppData\Local\Temp\opencode\` or the process's own log) to determine why it is stuck, **fix the root cause**, and only then restart and re-verify. Never leave a companion process (e.g. a dev server or a puppeteer browser session) wedged, and never spawn redundant duplicate processes while troubleshooting — kill first, diagnose, then restart.
